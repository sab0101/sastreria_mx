# Sastrería SaaS

Sistema de seguimiento de órdenes para sastrerías.

## 🔧 Configuración

1. Crear proyecto en Firebase
2. Habilitar autenticación con Email/Password
3. Copiar las reglas de Firestore
4. Configurar la API Key en script.js

## 📱 PWA

La aplicación es instalable como PWA en dispositivos móviles.
